A program that writes one line to `/output/entry.txt` (107 characters, inside the 200-character gate): "Monday: my alarm snoozed itself, my coffee went cold, and the only thing delivered on time was more Monday." Monday reviewed like a bad product: the alarm gives up first, the coffee goes cold, and the only thing Monday delivers on time is more Monday — a punch a coworker would repeat the next morning.

## Run it

```sh
python3 main.py
```
